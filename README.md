# Advancing AI Capabilities and Evolving Labor Outcomes
This repository contains code and data used in the creation of ***Advancing AI Capabilities and Evolving Labor Outcomes*** by Yong Suk Lee and Jacob Dominski.

## Repository Structure
### Code
- `README.md` - This file, explaining the project.
- `ai_exposure_aggregation_onet_level.do` - Stata script for aggregating task exposure scores to ONET-level occupational exposure scores and cleaning this data before the crosswalk.
- `ai_exposure_crosswalk_to_scores_v4.do` - Stata script for mapping ONET level exposure scores to CPS level occupations and merging exposure scores with CPS and ASEC data.
- `analysis_cps_monthlies_050725` - Stata script for CPS data cleaning and analysis. This script includes code for cleaning CPS data and the individual level and constructing outcome variables, controls, and weights. It also contains the main first-differenced specifications, as well as alternative specifications using 3-month periods, varied outcome intervals and exposure definitions, and different sample size cutoff thresholds.
-  `het_061725.do` - Stata script for heterogeneity analysis of CPS data. This script extends the cleaning and construction procedures in analysis_cps_monthlies_050725 by creating outcomes, controls, and weights at the occupation-demographic group level (e.g., by sex, age, and education). It includes code for generating the heterogeneity specifications shown in the paper, as well as additional exploratory regressions that vary by demographic groupings.
-  `2010occ_main_analysis_052925` - Stata script for creating crosswalks between occupation coding systems and conducting main analyses at the 2010 occupation level. This script includes code to construct crosswalks from the 2010 CPS to the IPUMS harmonized occ2010 classification system, as well as from the 2018 CPS system to occ2010, which is used to map AI exposure scores to this level. It also includes cleaning and construction of outcomes, controls, and weights, along with code to aggregate task indices and the work-from-home indicator to the occ2010 level. Finally, it contains the main first-differenced specifications at the occ2010-level and additional analyses using varied outcome periods (including control periods), exposure stages, and an indicator for remote work.
-  `AA_routine_measures_.do` - Stata script for constructing task indices based on Acemoglu and Autor’s (2011) methodology. This script includes code to compute all task measures used in analysis, and to map them to the CPS occupational classification system. It also contains preliminary analysis, which is superseded by more robust analysis in other scripts in the repository.
- `WP_051425` - Python notebook used to generate many of the figures in the paper. This includes visualizations of the evolution of exposure scores over time, correlations between exposure measures, the employment distribution versus exposure, cumulative distribution functions (CDFs) of exposure by demographic characteristics, and occupational case study figures
-   `resid_bubbles_v2.ipynb` - Python script for creating the residualized bubble scatter plots.
-   `Evolving_Outcomes.ipynb` - Python script for creating the figures showing how estimated coefficients change by outcome period and exposure stage.

### Data
- `monthly_cps_v1.dta` - A CPS extract containing observations from January 2010 through January 2025. Note: This data is too large to upload directly to GitHub.
- `monthly_cps_march25.dta` A CPS extract containing observations from January 2020 through March 2025. Note: This data is too large to upload directly to GitHub.

- `Llama_onetdata.dta` - AI exposure estimates at the ONET occupation level generated by using the Llama LLM
- `Task_statements_claude_output` - AI exposure estimates at the ONET task level generated by using Claude
- `Task_statements_output` - AI exposure estimates at the ONET task level generated by using OpenAI
- `Task_Ratings.xlsx` - Frequency, importance, and relevance score for each ONET task. Used while aggregating task scores to occupation scores in `ai_exposure_aggregation_onet_level.do`
