# AI-Workforce-Dynamics
This repository contains code and data used in the creation of ***Workforce Dynamics in the Age of AI*** by Yong Suk Lee.

## Repository Structure
### Code
- `README.md` - This file, explaining the project.
- `ai_exposure_aggregation_onet_level.do` - Stata script for aggregating task exposure scores to ONET level exposure scores and cleaning this data before the crosswalk.
- `ai_exposure_crosswalk_to_scores_v2.do` - Stata script for mapping ONET level exposure scores to CPS level occupations.
 - **TODO:** Integrate code from `cps_clean_merge.do` so all aggregation, merging, and cleaning happens in one file.
- `cps_event_study.do` - Stata script for creating the event studies used in the exploratory phase of the paper.
### Data
- `monthly_cps_v1.dta` - A CPS extract containing observations from January 2010 through January 2025
- `monthly_cps_w_ai_scores.dta` - The previous CPS extract cleaned and with AI exposure scores for each occupation. Note: This data is created using `ai_exposure_crosswalk_to_scores_v2.do`.
- `Llama_onetdata.dta` - AI exposure estimates at the ONET occupation level generated by using the Llama LLM
- `Task_statements_claude_output` - AI exposure estimates at the ONET task level generated by using Claude
- `Task_Ratings.xlsx` - Frequency, importance, and relevance score for each ONET task. Used while aggregating task scores to occupation scores in `ai_exposure_aggregation_onet_level.do`
